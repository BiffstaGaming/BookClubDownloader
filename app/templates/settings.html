m4b-tool works in a hidden .bookclub-work folder here. When no library template is set below, finished books are also filed here as Author/Series/1 - Title/Title.m4b.
Where finished books go. Variables: [Author] [Title] [Series] [BookNumber] [Narrator] [Year] [Filename]. Empty parts (e.g. [Series] for a standalone book) are dropped. Audiobookshelf needs each book in its own folder.
Only folders inside the downloads path above are ever deleted.
m4b-tool encodes one chapter per job simultaneously (--jobs). Most audiobooks have 10–30 chapters, so setting this above that count gives no extra benefit. A good starting point is half your CPU core count — e.g. 16 on a 32-core machine — to leave headroom for other services. Default: 1 (single-threaded).
For speech, 64k sounds the same as 128k and encodes roughly twice as fast.
